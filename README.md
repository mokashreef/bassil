# موقع باسل - BASSEL Portfolio & CMS

موقع تعريفي (Portfolio) احترافي، متكامل، ومصمم خصيصاً لعرض أعمال وخدمات المصمم الجرافيكي ومونتير الفيديو **باسل**. يعكس الموقع هوية بصرية عصرية، ويوفر تجربة مستخدم (UX) سلسة وجذابة لزوار الموقع والعملاء المحتملين.

---

## ✨ مميزات الموقع (الواجهة الأمامية)

تم تصميم وتطوير واجهة الموقع لتكون واجهة احترافية تبرز الإبداع في كل تفصيلة، وتشمل المميزات التالية:

- **تصميم عصري ومتجاوب (Responsive):** يعمل بكفاءة وشكل ممتاز على جميع الأجهزة (الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة).
- **شاشة تحميل (Loading Screen):** شاشة تحميل أنيقة تظهر شعار "BASSEL" قبل دخول الزائر للموقع.
- **تأثيرات حركية (Animations):** حركات انسيابية للعناصر عند التمرير (Scroll Reveals) تعطي حياة وديناميكية للموقع.
- **القسم الرئيسي (Hero Section):** واجهة ترحيبية جذابة تحتوي على إحصائيات تفاعلية (عدادات أرقام) لسنوات الخبرة والمشاريع المكتملة.
- **قسم "من أنا" (About):** يعرض النبذة التعريفية بالإضافة إلى أشرطة تقدم (Progress Bars) تستعرض مستوى المهارات في برامج Adobe.
- **معرض الأعمال (Portfolio):** شبكة صور (Grid) بتأثيرات بصرية رائعة عند التمرير (Hover Effects) لعرض تصاميم الجرافيك والفيديوهات.
- **قسم الخدمات (Services):** بطاقات (Cards) منظمة تستعرض الخدمات المقدمة مع أيقونات معبرة لكل خدمة.
- **تواصل معي (Contact):** نموذج تواصل متكامل، ومعلومات الاتصال المباشرة وروابط منصات التواصل الاجتماعي (إنستغرام وبيهانس).

## ⚙️ نظام إدارة المحتوى (لوحة التحكم CMS)

### ❌ كيف كان الموقع بالسابق؟ (الموقع الثابت)
في نسخته الأولى، كان الموقع عبارة عن صفحة **HTML ثابتة (Static HTML)**. 
هذا يعني أن "باسل" كان يواجه صعوبة كبيرة في تعديل أي شيء؛ فإذا أراد إضافة صورة جديدة لمعرض أعماله، أو تغيير نص في قسم "من أنا"، كان يضطر إلى:
1. فتح ملف `index.html` والبحث بين مئات الأسطر البرمجية.
2. تعديل الكود يدوياً، مما قد يؤدي إلى أخطاء غير مقصودة تفسد تصميم الموقع.
3. عدم القدرة على التحديث السريع من الجوال أو الأجهزة الأخرى التي لا تحتوي على أدوات برمجة.

### ✅ الترقية للاحترافية (وجود لوحة التحكم)
تم تحويل الموقع من مجرد صفحة ثابتة إلى **نظام إدارة محتوى (CMS) ديناميكي متكامل**، دون المساس بتصميمه الأصلي الفاخر:
1. **قاعدة بيانات مبسطة (`data.json`):** تم سحب جميع النصوص والصور والروابط من الكود البرمجي وتخزينها في ملف بيانات مستقل ومنظم.
2. **محرك PHP (`index.php`):** أصبحت واجهة الموقع تقرأ البيانات تلقائياً من `data.json` وتعرضها للزوار بسرعة فائقة.
3. **لوحة تحكم مرئية فاخرة (`admin/index.php`):** تم بناء لوحة تحكم (Dashboard) عصرية وآمنة بكلمة مرور. الآن يستطيع باسل:
   - تغيير أي نص أو عنوان أو رابط في الموقع من خلال نماذج (Forms) مريحة.
   - إضافة وإزالة الصور والأعمال والخدمات بضغطة زر.
   - حفظ التعديلات لتنعكس فوراً على الموقع الأساسي دون الحاجة لكتابة أو تعديل أي سطر كود!

## 🛠 المتطلبات لتشغيل الموقع

بما أن الموقع أصبح يعمل بـ PHP ويحتوي على لوحة تحكم، يجب تشغيله على خادم محلي (Local Server) أثناء التطوير، أو استضافة ويب تدعم PHP.

1. قم بتثبيت خادم محلي مثل **XAMPP** أو **WampServer**.
2. انسخ مجلد المشروع `BASEL` إلى مسار `htdocs` الخاص بالخادم.
3. افتح متصفحك وتوجه إلى: `http://localhost/BASEL/` لعرض الموقع.

---

## 🔐 الدخول إلى لوحة التحكم (Admin Panel)

1. **الرابط:** توجه إلى `http://localhost/BASEL/admin/`
2. **كلمة المرور:** لتسجيل الدخول بأمان، استخدم كلمة المرور:
   `Basil1234#`
3. قم بتعديل ما تريده من أقسام (الرئيسية، الأعمال، الخدمات، إلخ)، واضغط على الزر الأزرق العائم في أسفل الصفحة **"حفظ جميع التعديلات"**.

## 📁 هيكلية المشروع

```text
BASEL/
│
├── index.php           # واجهة الموقع الأساسية الديناميكية
├── data.json           # ملف قاعدة البيانات الذي يخزن جميع المحتويات القابلة للتعديل
├── style.css           # ملفات التنسيق الأساسية (CSS)
├── script.js           # ملفات التأثيرات الحركية والتفاعل (JS)
├── images/             # مجلد الصور الأساسية للموقع
│
└── admin/              # مجلد لوحة التحكم (محمي)
    ├── login.php       # واجهة تسجيل الدخول (نظام الحماية)
    ├── index.php       # لوحة التحكم العصرية (الـ Dashboard)
    ├── save.php        # لمعالجة بيانات لوحة التحكم وحفظها في data.json
    └── logout.php      # تسجيل الخروج
```
