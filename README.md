# BASSEL Portfolio | موقع شخصي لباسل

موقع شخصي (Portfolio) احترافي مصمم خصيصاً لاستعراض أعمال "باسل"، مصمم الجرافيك ومونتير الفيديو. يعرض الموقع نبذة شخصية، المهارات التقنية، معرض الأعمال (تصاميم وفيديوهات)، الخدمات المقدمة، وطرق التواصل.

## 🌟 المميزات (Features)

*   **تصميم عصري وجذاب:** واجهة مستخدم حديثة تعكس الاحترافية في مجال التصميم المرئي.
*   **متجاوب بالكامل (Fully Responsive):** يتكيف الموقع بسلاسة مع جميع مقاسات الشاشات (الهواتف الذكية، الأجهزة اللوحية، وأجهزة الكمبيوتر).
*   **تأثيرات حركية (Animations):** استخدام تأثيرات بصرية ناعمة عند التمرير (Scroll Reveal) لتحسين تجربة المستخدم.
*   **معرض أعمال احترافي:** تقسيم واضح لأعمال التصميم الجرافيكي وأعمال المونتاج (مع إمكانية جلب الفيديوهات من يوتيوب).
*   **شريط تقدم المهارات:** عرض مرئي لمستوى الإتقان في برامج أدوبي (Photoshop, Illustrator, Premiere Pro, After Effects).
*   **وضع ليلي/داكن أنيق:** ألوان داكنة مريحة للعين تبرز جمالية التصاميم والألوان المستخدمة.

## 🛠 التكنولوجيا المستخدمة (Tech Stack)

تم بناء هذا المشروع باستخدام التقنيات الأساسية لتطوير الويب:

*   **HTML5:** لبناء الهيكلية الأساسية للموقع بطريقة دلالية (Semantic).
*   **CSS3:** لتنسيق الموقع بالكامل، مع استخدام المتغيرات (Variables)، Flexbox، و Grid Layout.
*   **JavaScript (Vanilla JS):** لإضافة التفاعلية للموقع (مثل القائمة الجانبية في الهاتف، تأثيرات التمرير، عداد الأرقام، وجلب الفيديوهات).
*   **FontAwesome:** لاستخدام الأيقونات الجاهزة في جميع أنحاء الموقع.

## 📂 هيكلية المشروع (Project Structure)

```text
bassil-main/
│
├── index.html       # الصفحة الرئيسية والوحيدة للموقع
├── style.css        # ملف التنسيقات (CSS)
├── script.js        # ملف التفاعلية والبرمجة (JavaScript)

```

## 🚀 طريقة التشغيل (How to Run)

المشروع عبارة عن صفحات ويب ثابتة (Static Web Pages)، لذلك لا يتطلب أي خوادم أو بيئة تشغيل معقدة.

1.  **تحميل المشروع:** قم بتحميل الملفات أو استنساخ المستودع (Clone).
    ```bash
    git clone https://github.com/your-username/bassel-portfolio.git
    ```
2.  **تشغيل الملف:** فقط قم بفتح ملف `index.html` في أي متصفح ويب حديث (مثل Google Chrome أو Firefox أو Safari).
3.  **للتعديل (اختياري):** يمكنك فتح المشروع في أي محرر نصوص (مثل VS Code) واستخدام إضافة "Live Server" لمشاهدة التعديلات بشكل مباشر.
